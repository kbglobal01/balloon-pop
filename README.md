# 풍선 터뜨리기

하늘에서 올라오는 풍선을 30초 동안 터뜨리는 게임이에요. 마우스와 터치 모두 돼요.

- 풍선을 누르면 '펑!' +1점, 금색 별풍선은 언제나 +3점
- '오늘의 색'을 고르면 다른 색 풍선을 눌렀을 때 '앗!' -1점
- 속도: 천천히 / 보통
- 30초가 끝나면 '풍선 대장!'

## 인터넷으로 하기

GitHub Pages를 켜면 `https://kbglobal01.github.io/balloon-pop/` 에서 바로 할 수 있어요.
게임 시작 화면의 '휴대폰으로 하기'를 누르면 그 주소의 QR코드가 나와요.

## 인터넷 없이 시연하기

`download/풍선게임_오프라인.zip` 을 받아 노트북에서 실행하세요. 자세한 방법은 압축 파일 안의 `사용법.txt`에 있어요.
노트북과 휴대폰이 같은 와이파이(휴대용 공유기나 휴대폰 핫스팟도 됨)에 있으면 인터넷 없이 QR코드로 바로 할 수 있어요.

## 파일

- `index.html`, `fonts/` : 게임
- `download/` : 인터넷 없이 시연하는 프로그램 묶음 (윈도우, 맥)
- `offline-server/` : 그 프로그램의 소스 코드 (Go). `go build` 로 다시 만들 수 있어요.
